The Kind of Systems We Build

RoxAI is a young agency — we'd rather show you exactly what we build than pad this page with claims we can't back up yet. Below are representative examples of the automation systems we design for private and international schools, based on the admin work we hear about most often. See how engagements are priced.

Note: these are illustrative examples of our build approach, not completed client case studies. As we onboard schools, we'll replace these with real, named results (with permission).
Admissions & Enrollment

Inquiry-to-Enrollment Agent

For schools losing prospective families between "I'm interested" and a signed enrollment. An agent that responds to inquiries within minutes, qualifies the family against space and grade availability, and keeps every lead moving instead of sitting in an inbox.

WhatsApp / EmailGoogle Sheets or AirtableCalendar syncAI response drafting

How it typically works

  1. 1Inquiry comes in via web form, WhatsApp, or email and is logged automatically.
  2. 2The agent replies with grade/space availability and next steps — same day, not same week.
  3. 3Qualified families are auto-scheduled for a tour or call.
  4. 4Admissions staff see a live pipeline instead of a scattered inbox.
Parent Engagement

Parent Communication Assistant

For the fee reminders, event notices, and "did you get my message?" follow-ups that eat a front-office team's day. A WhatsApp- or SMS-based assistant that answers common parent questions instantly and escalates anything it can't handle to a human.

WhatsApp Business APISMSSchool records lookupHuman handoff

How it typically works

  1. 1Parents message the school's existing WhatsApp number as normal.
  2. 2The assistant answers routine questions (fee balance, term dates, pickup policy) instantly.
  3. 3Anything sensitive or unclear routes straight to office staff, with context attached.
  4. 4Broadcast announcements go out to the right parent groups automatically.
Teacher Support

Admin-Off-Their-Plate Agent

For the attendance logging, report-card assembly, and scheduling admin that pulls teachers away from actual teaching. Built to sit inside tools teachers already use, not add another app to learn.

Google WorkspaceAttendance systemsTemplate automation

How it typically works

  1. 1Attendance and grade entries sync from whatever teachers already use.
  2. 2Recurring admin (schedules, routine notices) gets auto-generated from templates.
  3. 3Teachers review and approve rather than build from scratch.
  4. 4Time saved gets redirected to actual classroom prep.
Tech Operations

Systems Integration Layer

For schools running three or four disconnected tools — a fee system, a school management platform, a spreadsheet nobody trusts — where the same data gets typed in twice. We connect what already exists instead of ripping it out and starting over.

Zapier / MakeAPI integrationsData cleanup

How it typically works

  1. 1We map what tools the school already relies on and where data breaks between them.
  2. 2We connect the highest-friction gaps first — usually fee records and communication.
  3. 3Staff keep using the tools they know; the syncing happens behind the scenes.
  4. 4One source of truth, instead of three spreadsheets that disagree.
